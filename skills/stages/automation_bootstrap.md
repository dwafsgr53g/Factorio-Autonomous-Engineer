# Stage skill: automation bootstrap

## Strategic objective

Turn the initial foothold into a stable first automated production system.

The current prototype exposes the proven high-level gathering task, starting-site selection and bounded `assist_construction` for pending ghosts. Machine configuration, power wiring, crafting chains, module insertion and full base layout generation are not automated. Use construction assistance for small named/test plans or player ghosts within the executor work area; do not invent coordinates or a complete factory layout.
